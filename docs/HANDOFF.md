## 4. 함정 — 반복하지 말 것

이번 세션에서 실제로 밟은 것들.

1. **httpx 클라이언트 공유 금지**
   h2 커넥션이 한 번 깨지면 풀에 남아 이후 전량 `LocalProtocolError`.
   13,286건 스윕에서 251건 성공 후 13,025건 실패. 요청마다 새 클라이언트를 만들 것.
   `http2=False`는 대안이 아니다 — Akamai가 403을 준다.

2. **연속 대량 요청은 velocity 차단을 부른다**
   전용 UA는 화이트리스트 **승인 완료** 상태지만, 화이트리스트는 봇 탐지 면제이지
   rate limit 면제가 아니다. 동시성 16으로 80분 연속 훑자 UK/DE가 403을 받았고
   같은 UA로 US는 200이었다(국가별로 갈리면 속도 위반 신호).

3. **응답을 받았다고 내용이 있는 건 아니다**
   `#10` 패치 1차에서 `soup` 존재만 확인하고 저장해, 빈 HTML을 받은
   글로벌 뉴스룸 99건이 1.0%로 잘못 찍혔다(실물은 합계 12로 통과).
   갱신 전에 값의 타당성(예: 랜드마크 0개)을 검사할 것.

4. **오프라인 재채점 금지**
   `run_results`의 `json_ld.raw`는 전체 노드를 보장하지 않는다.
   2026-06에 이걸로 130건을 오염시켰다. 재측정은 반드시 다시 fetch.
   단, 저장된 `value`에 **원측정 수치**가 있으면(예: `6/42`) 재계산은 안전하다.

5. **캐시 키에 구분자를 빠뜨리지 말 것**
   `#19`가 `base_url`만으로 키를 만들어 11개국이 `/us` 결과를 공유했다.
   `base_url`은 전 국가가 `https://www.lg.com`으로 동일하다.

6. **작은 표본으로 결론 내지 말 것**
   PDP #23을 20건 표본의 10.0%로 "가장 큰 갭"이라 단정했으나
   60건에서는 15.5%로 기존과 차이가 없었다.

7. **대조군 없이 도구를 믿지 말 것**
   CSR 측정에서 UK/DE/BR/CA가 0으로 나와 "템플릿에 요약이 없다"고 결론냈는데,
   대조군(US)을 넣어보니 도구는 정상이었고 결론도 맞았다 — 하지만 대조군이
   없었다면 틀린 결론을 확정할 뻔했다. 항상 양성 대조군을 넣을 것.
