# Hiro 릴리즈 노트

Hiro(Dotcom Readability Checker)의 변경 이력. 최신이 위.

- 채점·감사 결과나 화면에 영향이 있는 변경을 커밋할 때마다 맨 위 날짜 블록에 한 줄 추가한다(같은 날이면 그 블록에 이어서).
- 한 줄 = `[구분] 무엇이 바뀌었나 — 왜/영향 (커밋)`. 구분: 채점 · 모델 · 학습 데이터 · 감사 운영 · 화면 · 확장 · 이름 · 문서.
- 점수에 영향이 있으면 영향 국가·항목·폭을 적는다. 배포 상태(로컬만 / 푸시 / 웹스토어)도 적는다.
- 버전: 크롬 확장은 `extension/manifest.json`(커밋 훅이 자동 증가), API는 `main.py` FastAPI version.

## 진행 중 · 미결

- **v3c 학습 중**(10-21 시작): v3b에서 '기술 작동 설명 = 정의 y'만 빼고 인용 y로만 학습. 끝나면 v2와 같은 정답으로 비교 후 배포 여부 결정. 파이프라인 `reports/shadow_llm/train/pipeline_v3c.sh`.
- **월간 감사 10-25 02:00**: 이 Mac 로컬 + 모델로 실행. 예상 2~4일.
- **크롬 웹스토어**: v2.4.2 ZIP 재업로드 필요(`docs/extension-publish-guide.md`).
